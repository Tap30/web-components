Add the `Row` component: a list row with leading and trailing slots, a label
and optional description (with a `reversed` emphasis), an optional leading
badge, a divider, and a `textOverflow` choice between wrapping and ellipsis.
With `href` it renders as a link and with `onClick` as a button; otherwise it is
a `<div>` that Base UI's `render` prop can turn into another element.
