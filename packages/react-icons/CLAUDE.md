## Package: `@tapsioss/react-icons`

Tapsi Design System icons as React components. Each icon is a thin React SVG
wrapper generated from `@tapsioss/icons`.

## Commands

```bash
# Build (generates and compiles all React icon components into dist/)
pnpm build
```

There is no dev/watch or test mode. Rebuild after `@tapsioss/icons` changes.

## Architecture

### Fully generated output

The entire `dist/` is generated by `scripts/build.ts`. There is no hand-written
component source — only `src/base-icon.tsx` is manually maintained.

### Build process (`scripts/build.ts`)

1. **Import** all icons from `@tapsioss/icons` (the workspace package).
2. For each icon entry, **render** `templates/react-icon.txt` (Mustache) with:
   - `name` — PascalCase icon name (e.g., `ArrowDown`)
   - `paths` — JSX `<path>` elements with `d`, `clipRule`, `fillRule`,
     `xlinkHref` props
   - `dataUrl` — base64 data URL passed as a static property for docs/Storybook
     previews
3. **Write** each rendered component to `dist/<Name>.tsx`.
4. **Append** `export { default as <Name> } from "./<Name>.tsx"` to
   `dist/index.ts`.
5. **Copy** `src/base-icon.tsx` into `dist/`.
6. **Compile** `dist/` with `tsc` (produces `.js` + `.d.ts`).
7. **Delete** intermediate `.tsx` and `.ts` source files from `dist/`, keeping
   only `.js` and `.d.ts`.

### `src/base-icon.tsx` — the only manually maintained file

`BaseIcon` (exported as `default`) is an SVG wrapper component with these props:

| Prop       | Type               | Default       | Description                           |
| ---------- | ------------------ | ------------- | ------------------------------------- |
| `children` | `ReactNode`        | —             | SVG path elements                     |
| `viewBox`  | `string`           | `"0 0 24 24"` | SVG viewBox                           |
| `title`    | `string`           | —             | Accessible title (sets `role="img"`)  |
| `size`     | `number \| "auto"` | `"auto"`      | Pixel size or `"auto"` (fills parent) |
| `slot`     | `string`           | —             | Web component slot assignment         |

When `size="auto"`, the icon renders at `width: 100%; height: 100%`. When a
number, it sets width/height in `rem` (`size / 16`). Color is always
`currentcolor`.

### Generated component shape

Each generated component wraps `BaseIcon`:

```tsx
import Icon from "./base-icon.tsx";

const ArrowDown = props => (
  <Icon {...props}>
    <path d="..." />
  </Icon>
);

ArrowDown.dataUrl = "data:image/svg+xml;base64,...";
export default ArrowDown;
```

### Dependency chain

`@tapsioss/react-icons` depends on `@tapsioss/icons` (workspace). If icons are
added or modified, rebuild in order:

1. `pnpm build` in `packages/icons`
2. `pnpm build` here

From the repo root: `pnpm build:packages` handles the order via wireit.
