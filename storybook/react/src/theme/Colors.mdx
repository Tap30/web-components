# Colors

Read live from `packages/theme/src/default-theme/tokens.ts`. Every swatch is
painted with its CSS custom property, so what you see is what the browser
resolves.

Semantic tokens are the ones to use in components. The raw palette exists to
back them and should rarely be referenced directly.
