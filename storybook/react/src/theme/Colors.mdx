# Colors

Two layers. The **palette** holds the raw literals and is the same whatever you
render; the **theme** gives each palette entry a job and is what varies by
product and mode.

Components reference the theme layer only — never the palette. That is what lets
the same component render as ride-light or drive-dark with no code change.

Swatches below are painted from the CSS custom property and read their printed
value from the TypeScript set, which is generated separately. A swatch whose
colour disagrees with its printed value means the two have drifted.

Pick a theme below to switch which set is shown; every block on this page
follows it. (Docs pages cannot read the toolbar, so they carry their own control
— the toolbar drives the component stories.)
