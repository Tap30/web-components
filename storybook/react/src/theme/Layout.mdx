# Layout

Every length in the system is **rem**, converted once at the Figma boundary, so
a user who raises their browser font size scales the whole interface rather than
just the text.

## Number

The raw scale every length above resolves to, from `@tapsioss/theme/tokens.css`.
The key is the **pixel value in Figma**, so `--tapsi-number-16` is `1rem`.

Border widths come from here too — `--tapsi-number-1` and `--tapsi-number-2`
replace the retired `--tapsi-stroke-1` and `--tapsi-stroke-2`.
