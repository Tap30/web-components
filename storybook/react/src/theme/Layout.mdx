# Layout

Spacing, radius and stroke scales.

## Spacing

The numbering is an **ordinal index, not a multiplier** — `--tapsi-spacing-4` is
`0.5rem`, not `4` of anything. Note also the half-step `3-1` sitting between `3`
and `4`.
