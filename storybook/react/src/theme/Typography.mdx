# Typography

Each variant expands to four CSS custom properties — `-font`, `-size`,
`-height`, `-weight`. The samples below are styled from those variables, not
from the JS values.

Note that `-height` is a **unitless ratio** and `-weight` a raw number, so both
can be used directly in CSS without conversion.

Every variant resolves its font through `var(--tapsi-typography-font-family)`,
currently set to <code>{tokens.typography["font-family"]}</code>.
